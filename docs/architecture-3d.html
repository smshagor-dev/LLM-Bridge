01 · REQUEST

PC → LLM Bridge

Prompt and model location enter the Rust control plane. CPU compatibility and budgets are checked before native execution.

02 · SOURCE

Bridge → GGUF storage

Today the bounded reader opens an accessible local file, including a mounted drive when the OS exposes it as a regular file.

03 · COMPUTE

Tensor chunks → CPU

Streamed decoder uses indexed weight ranges and bounded staging; activation/KV memory still counts separately. Optional trusted integrity validation applies where supported.

04 · RESPONSE

Decoder → PC

Greedy tokens, optional logits and metrics return. Google Drive would first require a secure, verified download/staging provider; that adapter is not implemented.

Architecture status: local bounded GGUF reads and experimental dense-Llama streamed generation exist. Direct Google Drive authentication/range streaming, remote provider scheduling, arbitrary-model compatibility and physical 2 GB machine operation are not verified or implemented. This animation is a visualization of implemented and planned paths, not a test result. Repository README · Streamed decoder details.
